How to get a CSV

  • Most platforms let you download post-level analytics from their creator or business tools. Use “Export” or “Download data” and choose CSV. If you only get an Excel file, open it and use File → Save as / Download → CSV.
  • If a platform has no export, copy the numbers into a spreadsheet with one row per video and save it as CSV, or use manual entry.
  • Column names differ between platforms and change over time. That's why step 2 lets you match them yourself. Your choices are remembered for files with the same columns.
  • Importing the same file twice is blocked. A newer export of the same videos adds a new dated snapshot, so you can see how the numbers grew.
